## 🔬 What I'm working on

- **EEG transient detection** — spike detection on EEG traces with an AR model + whitening filter, validated on an Arduino Uno
- **Glucose modelling** — simulation and analysis of glucose dynamics with ReplayBG
- **Neural chess engine** — supervised pretraining on PGN games, then reinforcement-learning fine tuning
- **FocusMaxxer** — Flutter app for tracking and training cognitive performance
