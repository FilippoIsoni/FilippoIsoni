## 🔬 Selected Projects

**[EEG Transient Detection](https://github.com/FilippoIsoni/Riconoscimento-di-transitori-su-tracciato-EEG)** · `MATLAB` `Simulink` `Arduino`
Detection of epileptic spikes in EEG traces. Background activity is modelled as an AR(p) process (order selected by AIC), then a whitening filter plus a threshold on prediction-error power isolates the transients. Ported to an Arduino Uno R3 under a 2 KB SRAM budget.

**[ResNet Chess Bot Fine-Tuned with RL](https://github.com/FilippoIsoni/Resnet-Based-Chess-Bot-Fine-Tuned-with-RL)** · `Python` `PyTorch`
A convolutional ResNet trained from scratch on PGN games, then fine-tuned with reinforcement learning and paired with MCTS. No distillation from existing engines — the point is the learning pipeline, not the Elo.

**[SHARP-HAR](https://github.com/FilippoIsoni/sharp-har)** · `Python` `PyTorch`
WiFi-based human activity recognition with SimCLR contrastive pretraining on an asymmetric Inception encoder, plus adversarial heads to disentangle the environment from the activity. Reproducible splits, YAML configs, notebooks as thin runners.

**Glucose management with ReplayBG** · `Python` `MATLAB`
Hypoglycemia rescue handler ported from MATLAB to Python, with physiologically grounded dose computation — one variant driven by dynamic risk, one by a 15-minute forecast from a first-order Taylor expansion.

**FocusMaxxer** · `Flutter` `Dart`
Cognitive performance app implementing the SAFTE biometric model, shipped as a Flutter web build on GitHub Pages.
